# CertList

Zertifikate mit Aussteller, Name, Monat und Prüf-Link; die ganze Einheit ist der Link zum öffentlichen Badge.

**Consumer liefert:** `items` (`{ issuer, name, date, verifyUrl, verifyLabel }`), neueste zuerst.

- Kräftige Linie oben statt Karte; Hover färbt sie Kupfer, verdickt den Unterstrich des Nachweis-Links und schiebt den Pfeil diagonal nach. Fokus legt den Ring um die ganze Einheit.
- Kein Hinweis „abgelaufen“: Gültigkeit zeigt der Nachweis-Link, und wer sich auskennt, weiß, dass Zertifikate ablaufen. Alle Zertifikate sehen gleich aus.
- Vorgelesen wird „SAFe 6 Architect: Auf Credly prüfen (externe Seite)“. Im PDF wird die URL ausgeschrieben.
