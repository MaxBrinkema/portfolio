# Portrait

Das Profilfoto im Format 4 : 5, eckig, ohne Rahmen und Schatten – das einzige Foto der Seite.

**Consumer liefert:** `src` und optional `alt` (Standard „Porträt von Max Brinkema“). Ohne `src` erscheint ein gestrichelter Platzhalter.

- Das Foto liegt in zwei Größen vor (1×, 2×), `loading="lazy"` außer im Hero.
