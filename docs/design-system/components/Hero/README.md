# Hero

Der Einstieg der Startseite wie in Signal: Statuszeile, Begrüßung „Hallo, ich bin Max.“ in Serif, Rolle in Mono mit Kupfer-Cursor, zwei Sätze Einstieg, Aktionen und das Porträt.

**Consumer liefert:** `status` (optional), `greeting`, `role`, `intro` (mit einem `Mark`), `actions` (Lebenslauf-Download + „Projekte ansehen“), `portrait` (`{ src, alt }`).

- Kein Vollbild-Hero, kein Slogan, keine Tipp-Animation.
- Ab 48rem Containerbreite steht das Porträt rechts, darunter unter dem Text.
- Die Entscheidung der Richtung steht nicht hier, sondern im Projekte-Abschnitt (`DecisionCompare` an Case Study 01).
- Texte aus Werkstatt+ (V4) – vorläufig.
