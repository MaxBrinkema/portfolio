# Icon

Funktionale Strich-Icons (24er-Raster, 1,75 px, eckige Enden), die immer eine Handlung oder einen Status erklären.

**Consumer liefert:** `name`, optional `size`; `label` nur, wenn das Icon ohne Text steht.

- Keine dekorativen Icons: Jedes Icon steht neben einem Wort oder trägt ein `label`.
- Farbe kommt über `currentColor` vom Elternelement.
- Status-Glyphen (`status-*`) gehören zu `StatusBadge` und unterscheiden die ADR-Status über die Form, nicht nur über Farbe.
