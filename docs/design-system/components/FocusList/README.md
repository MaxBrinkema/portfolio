# FocusList

Nummerierte Liste kurzer Einträge – Schwerpunkte auf der Startseite, Qualitätsziele in arc42 (Q1–Q3), Kompetenzen im Lebenslauf (`numbered={false}`).

**Consumer liefert:** `items` (`{ title, text, num?, meta? }`), optional `numbered={false}`.

- Keine Kacheln und keine Icons: Einträge sind durch Haarlinien getrennt, die Nummer steht in `color-accent-text`.
- Zweispaltig, sobald jede Spalte 20rem breit sein kann.
- Keine Skill-Balken oder Prozentwerte.
