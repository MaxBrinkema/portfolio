# DocTabs

Unternavigation der Architektur-Doku am unteren Rand des Seitenkopfs: **Überblick · arc42 · Entscheidungen**, mit Mono-Zählern.

**Consumer liefert:** `items` (`{ id, label, count?, href }`), `current` (`aria-current="page"`).

- Der aktive Tab trägt den Seitengrund als Fläche und den Kupfer-Unterstrich – er wirkt aus dem Band herausgeschnitten.
- Tabs in Mono wie alle Bedienelemente.
- Zähler kommen aus den Inhalten (Anzahl Kapitel, Anzahl ADRs), nie von Hand.
