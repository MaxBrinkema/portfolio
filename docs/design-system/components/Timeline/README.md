# Timeline

Zeitleiste für den Lebenslauf, gegliedert nach Arbeitgebern: Zeitraum in Mono, Unternehmen als H3, darunter die Rollen in umgekehrter Reihenfolge – so werden Beförderungen beim selben Arbeitgeber sichtbar.

**Consumer liefert:** Stationen `{ org, period, current?, education?, steps: [{ title, period, current?, thesis?, bullets? }] }`, die neueste zuerst; `compact` blendet die Aufzählungen aus (Startseite).

- Aktuelle Station: Knoten in Kupfer, aktuelle Rolle mit „aktuell“. Steht bei einem Arbeitgeber nur eine Abschlussarbeit, ist der Knoten eckig (`education`).
- Abschlussarbeiten tragen die Pille „Abschlussarbeit“ und den Titel in Anführungszeichen.
- Ab 40rem Containerbreite steht der Zeitraum links der Achse. Im Druck bricht keine Rolle über eine Seite.
- Daten übernommen aus Werkstatt+ (V4) – vorläufig.
