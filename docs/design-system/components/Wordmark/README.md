# Wordmark

Die Wortmarke **brinkema■** bzw. das Monogramm **mb_** als Inline-SVG; die Tinte folgt `color-text`, der Cursor ist immer `color-accent`.

**Consumer liefert:** nichts außer `height` (Standard 24 px) und ggf. `variant="monogram"`.

- Im Header 22 px hoch. Unter 22rem Containerbreite wechselt der Header automatisch aufs Monogramm.
- Das Zeichen ist der einzige Ort, an dem der Akzent als Block in Logo-Größe auftritt – nie zusätzlich einen Akzent daneben setzen.
- Für `<img>`-Einbindung (E-Mail, OG-Bild, Favicon) die Dateien aus der Asset-Gruppe Logos nehmen.
