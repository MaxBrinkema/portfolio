# Callout

Hinweiskasten mit kräftiger Oberkante: „Was ich daraus gelernt habe“ (Akzent), „Hinweis“ (Tinte), „Achtung“ (Ocker).

**Consumer liefert:** `variant`, optional `title`, Inhalt als `children`.

- Pro Case Study genau ein `learned`-Kasten, am Ende vor dem Ergebnis.
- Keine Kästen mit farbiger linker Kante; die Kante liegt oben.
