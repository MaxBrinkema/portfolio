# SiteFooter

Footer auf `color-surface-strong`: oben die Kontaktzeile „Lust, über Architektur zu sprechen?“ mit der Mailadresse als Sekundär-Button, darunter Wortmarke, der Satz zur Machart der Seite, Links zu Architektur und Datenschutz und die Mono-Metazeile **„Code unter MIT · Inhalte © 2026 Max Brinkema“** mit dem Datum der letzten Aktualisierung.

**Consumer liefert:** `lang`, `email`, `updated` (aus dem Build), optional `cta={false}`.

- Die Lizenzzeile trennt bewusst Code (MIT) und Inhalte (©) – Texte, Foto und Lebenslauf stehen nicht unter MIT.
- `cta={false}` auf Hinweisseiten, auf denen die Kontaktmöglichkeit schon im Inhalt steht.
- Texte übernommen aus Werkstatt+ (V4) – vorläufig.
