# Tag

Technologie-Tag in Mono mit Haarrahmen; interaktiv als Filter (`aria-pressed`) in der Projektübersicht.

**Consumer liefert:** Text; für Filter `selected` und `onClick`.

- Statische Tags sind kein Bedienelement – kein Hover.
- Gewählter Filter: gefüllt in `color-text` plus Häkchen, nicht nur Farbe.
- Höchstens vier Tags pro Teaser.
