# Metric

Eine große Zahl mit ihrem Kontext: was gemessen wurde (fett) und warum es zählt (gedämpft).

**Consumer liefert:** `value`, `unit`, `label`, `context`, `size` (`xl` einmal pro Seite, `md`, `sm` in Reihen), optional `tone="accent"`.

- Nie eine Zahl ohne Kontext – keine Füllkennzahlen, keine Prozentbalken für Kompetenzen.
- Kräftige Linie (`border-rule`) über jeder Zahl; `tone="accent"` färbt Zahl und Linie Kupfer (nur ab 24 px, Kontrast 3,1:1).
- Ziffern tabellarisch, damit Reihen bündig stehen.
