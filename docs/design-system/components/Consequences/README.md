# Consequences

Die Konsequenzen eines ADR in zwei Spalten: **Positiv** (`+`, Linie in `color-success`) und **Negativ** (`−`, Linie in `color-error`).

**Consumer liefert:** `positive` und `negative` als Listen.

- Zwei Karten mit farbiger Kopflinie – gebaut wie der Callout; Titel in Mono-Versalien.
- Bedeutung tragen Überschrift und Zeichen; die Farbe ist nur Zusatz.
- Nebeneinander, sobald jede Spalte 15rem breit sein kann.
