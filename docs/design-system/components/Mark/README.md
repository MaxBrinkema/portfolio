# Mark

Textmarker für die eine wichtigste Aussage eines Absatzes: `color-accent-soft` als Grund, Text bleibt `color-text`.

**Consumer liefert:** den markierten Text als `children`.

- Höchstens ein Marker pro Absatz; er ersetzt fette Marketing-Phrasen.
- Übernommen aus Werkstatt+ (V4) als Teil der Stimme. Im Druck wird er zur Unterstreichung.
